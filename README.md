# Annihilation Blade

Annihilation Blade 是一个基于 SlashBlade Resharped 的 Minecraft 扩展模组，提供湮灭之刃、专属 SA“空间破碎”及配套合成材料。

## 支持版本

- `AnnihilationBlade-forge-1.20.1`：Minecraft 1.20.1 / Forge / Java 17
- `AnnihilationBlade-neoforge-1.21.1`：Minecraft 1.21.1 / NeoForge / Java 21

两个版本相互独立，请在对应目录中执行 Gradle 命令。

```powershell
cd AnnihilationBlade-forge-1.20.1
.\gradlew.bat build
```

```powershell
cd AnnihilationBlade-neoforge-1.21.1
.\gradlew.bat build
```
